Drive the C++ index

Pass each timestamp’s arrivals together. Use the next expiry to drive the clock during idle periods. At a shared timestamp, a single step applies expirations and arrivals before reporting changes.

index.step(t, arrivals, callback);
auto deadline = index.next_expiry();

Use KthWake in your event loop

Put one index after an ordered event stream. Pass the arrival count to step, dispatch the changed rule IDs, and arm one timer for the next idle deadline.
